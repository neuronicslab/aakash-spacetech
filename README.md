# AAKASH

Draft website for AAKASH, the IISc × ARTPARK Thematic Cluster for SpaceTech and Scientific Discovery.

Pages: `index.html` (home), `brainz.html`, `infrastructure.html`, `collaborators.html`, `news.html`.
Shared styles and scripts are in `assets/`, images in `assets/img/`.

Yellow "To be provided" boxes and grey image boxes mark content still to be added.
To use a photo, put it in `assets/img/` and replace the grey `<div class="ph">…</div>` with
`<img src="assets/img/your-photo.jpg" alt="Description">`.

Internal preview only: the sign-in is client-side and is not real security.
